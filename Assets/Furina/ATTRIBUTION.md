Changes: removed the scene backdrop and decorative platform; added lighting,
camera, whole-body sway, turning and bounce; rendered transparent PNG sprite
sheets with Blender 4.3. The source model has no skeleton or animation clips.
These animations do not articulate the arms, face or hair independently.

Each sheet contains 24 frames, arranged in 6 columns and 4 rows. Frames measure
256 by 320 pixels. `scripts/render_furina.py` reproduces the sheets from the
downloaded GLB. Rendering dependencies are build tools only; the application
uses embedded PNG resources through System.Drawing.
